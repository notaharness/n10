---
title: Context Switcher
description: Split one busy Claude Code session into contexts, one per topic, with Main chat kept for your conversation with Claude.
---

Context Switcher is a Claude Code plugin. Claude names a **context** for each
topic in a session, such as a CI run, a subagent's task or a message from
another session, and posts that topic's updates there. A sidebar lists
**Main chat** and every context, with a count of unread updates and a marker
on contexts waiting on you.

Click a context and the transcript shows only that topic; what you type there
goes to that context. Main chat holds your conversation with Claude, with a
one-line pointer to each update posted elsewhere.

It works in the Claude Code terminal in fullscreen only, and doesn't need n10
or Orchestra. The source is at
[github.com/notaharness/plugins](https://github.com/notaharness/plugins/tree/main/context-switcher).

## Install

```text
/plugin marketplace add notaharness/plugins
/plugin install context-switcher@notaharness
```

Turn on fullscreen with `/tui fullscreen`, then run `/contexts` to open the
sidebar.
